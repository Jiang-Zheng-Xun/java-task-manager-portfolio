## 案例目的

本案例在既有 Java Task Manager 後端新增 Task Evidence API，並記錄使用者與 AI 如何共同推進需求、實作、驗證及交付。

展示包含兩部分：軟體成果，以及使用者如何透過決策、操作反饋及驗收調整協作流程。案例也保留失敗成本與未解決的工具限制，不以成功結果取代完整過程。

## 軟體成果與證據

Evidence API 提供：

- `POST /api/tasks/{id}/evidence`：建立 Evidence。
- `GET /api/tasks/{id}/evidence`：分頁查詢 Evidence。
- V2 migration：建立 Evidence 資料表、外鍵與索引。

建立 Evidence 不修改 Task 欄位，也不代表任務已完成或已驗收。

實作涵蓋嚴格 JSON 輸入、Unicode 邊界處理、2000 code points 上限、交易內局部鎖逾時與父 Task 鎖定，以及依 `createdAt DESC, id DESC` 排序的分頁查詢。輸入驗證、錯誤邊界與資料庫規則詳見 API 契約及驗證文件。

本機階段 A 為分批取得的 42 類結果：609 項通過、40 項 skip。Commit IT 歷史結果獨立列示，不重複累加覆蓋。

PR CI 與合併後 CI 各執行 43 類、665 筆 testcase：625 通過、40 skip，failure 與 error 均為 0。兩次結果分開保存，不能相加為更多測試覆蓋。

## 協作分工

使用者負責需求、交付範圍、權限、重大取捨與最終驗收。

ChatGPT 協助規劃、整合正式交辦、審查來源與證據，並在授權範圍內核對 GitHub 狀態及更新 Issue。

Claude 在指定隔離環境、範圍與時間窗口內協助實作、排障及交付材料。AI 的摘要與成功宣告不單獨作為驗收依據。

Commit 中的 AI 標註用於記錄工具參與，不代表供應商背書。AI 協助審查也不取代人的最終責任；本案例未藉此認定使用者已具備獨立實作全部內容的能力。

## 使用者反饋帶來的流程調整

### 一、由拼接訊息改為唯一正式交辦

早期操作要求使用者自行組合草稿與授權，增加了遺漏資訊及使用錯誤窗口的可能。

使用者指出問題後，流程改為：先在 ChatGPT 確認範圍與限制，再由 ChatGPT 整合成一份自足的正式交辦。使用者只需整段貼給 Claude，不承擔上下文拼接責任。

這項調整明確了交辦入口，但沒有量測其節省時間的幅度。

### 二、依完整交付項目驗收

為尋找錯誤與增加可控制性，協作曾把工作切得過細，反覆處理內部檢查點及補證，增加使用者的確認、交接與等待負擔。

使用者要求維持原 Issue checkbox 的完整交付標準。執行可以依依賴分階段進行，但不把每個測試或工具檢查都拆成一次使用者驗收，也不為增加進度數字而新增 checkbox 或降低標準。

### 三、停止封裝工具修補循環

合併後同步與 branch 清理的紀錄已產生，但輔助封裝工具接連遇到規則字面文字誤判、重複寫入及收尾程式錯誤，形成多次 STOP。

最後改由使用者製作既有材料的傳輸 ZIP，供 ChatGPT 讀取原始紀錄審查。傳輸包沒有被冒稱為原批正式封裝，也沒有追認原批秘密掃描成功。

這個調整讓既有紀錄得以接受審查，但不表示原封裝工具已修好。r28～r30 的整批 STOP、原缺件與事後保存性質均保留。

## 工程反思：交付、可靠性與成本共同考量

檢查數量增加，不一定代表交付更可靠。每項檢查都應說明它保護的風險、所需證據及阻擋交付的條件。

本案例顯示，AI 可能因追求完整性、可控制性與狹窄操作範圍，持續追加工具及補證，讓工作從產品交付轉向維護交付程序。使用者必須反覆介入，原先希望減少的操作負擔反而增加。

改善原則是：

- 先守住資料、權限、秘密與必要契約等底線。
- 區分真正阻擋交付的缺口與可另行安排的改善。
- 以客戶價值、重要性、急迫性、依賴、延誤成本及投入排序。
- 同類阻擋反覆發生時，重新檢討流程，而非只增加下一批修補。
- 在既定品質底線內調整交付方式，不把「更多檢查」當成唯一解法。

## 可傳承的改善方式

可重用經驗以版本記錄，包含問題、適用情境、調整方式、權限、輸入輸出、驗證依據及已知限制。新專案依自身需求選用，不直接複製所有歷史限制。

自動化從穩定、重複且值得投入的步驟開始；模型、工具、依賴或環境改變時，重新評估受影響部分。

評估改善時，同時觀察交付前置時間、使用者介入次數、返工、等待、工具維護及交付後缺陷。這些是評估方法，不是本案例已取得的量化效益。

目標是讓使用者更多投入需求釐清、整體規劃、客戶溝通及重大決策，減少例行操作負擔。本案例尚不足以證明 AI 比原開發方式更快或更便宜。
